# Предложение

Реализация с использованием событийной модели.

При запросе пользователя формируется событие в топик `OsagoQuoteRequest` с данными для запроса в сервис `osago-aggregator`. В случае необходимости может быть отправлено событие об отмене запроса (например, если пользователь отменил его вручную или покинул сайт).

Результаты от каждой страховой компании поступают от сервиса `osago-aggregator` в топик `OsagoQuoteResponse`.

Для сервиса `osago-aggregator` выделена отдельная база данных, чтобы снизить влияние на другие сервисы и обеспечить возможность репликации и шардирования.

## Почему событийная модель

1. **Итеративная выдача результатов** — позволяет постепенно показывать предложения от страховых компаний, чтобы пользователь не покинул сайт из-за долгого ожидания.
2. **Удобство использования WebSocket** на стороне `core-app` — при поступлении события из топика ответ сразу передаётся пользователю, что быстрее, чем периодические запросы от клиента (client pull) или long polling.
3. **Гибкое масштабирование нагрузки** — нагрузка на `osago-aggregator` распределяется равномерно. В случае роста объёма данных можно использовать HPA (Horizontal Pod Autoscaler) для масштабирования.
4. **Лёгкое подключение аналитики** — можно просто подписывать дополнительные аналитические сервисы на нужные топики без изменения основной логики.

## Если использовать REST

1. **Синхронный REST** — в теории возможен, но приведёт к избыточной нагрузке, так как потребуется держать соединение открытым. Это может привести к разрывам соединений и потере данных при долгих ответах от страховых компаний.
2. **Создание задач через REST** — предполагает создание задач в `osago-aggregator`, что увеличивает время отклика из-за периодического опроса и необходимости хранения задач.
3. **Сложности с аналитикой** — подключение аналитических сервисов потребует дополнительных усилий.
4. **Сильная связанность сервисов** — если `osago-aggregator` недоступен, клиентские запросы могут быть потеряны.
5. **Плюс REST** — ниже трудозатраты на сопровождение Kafka и реализацию событийных интеграций.

#Топик OsagoQuoteRequest

Событие: QuoteRequestCreated

| Поле                   | Тип       | Обязательное | Описание                             |
| ---------------------- | --------- | ------------ | ------------------------------------ |
| `eventType`            | `string`  | Да           | Тип события: `"QuoteRequestCreated"` |
| `requestId`            | `string`  | Да           | Уникальный идентификатор запроса     |
| `timestamp`            | `string`  | Да           | Время создания события               |
| `client.firstName`     | `string`  | Да           | Имя клиента                          |
| `client.lastName`      | `string`  | Да           | Фамилия клиента                      |
| `client.birthDate`     | `string`  | Да           | Дата рождения                        |
| `client.licenseNumber` | `string`  | Да           | Номер водительского удостоверения    |
| `vehicle.vin`          | `string`  | Да           | VIN-номер автомобиля                 |
| `vehicle.plateNumber`  | `string`  | Да           | Гос. номер автомобиля                |
| `vehicle.make`         | `string`  | Да           | Марка автомобиля                     |
| `vehicle.model`        | `string`  | Да           | Модель автомобиля                    |
| `vehicle.year`         | `integer` | Да           | Год выпуска автомобиля               |


Событие: QuoteRequestCancelled

| Поле        | Тип      | Обязательное | Описание                               |
| ----------- | -------- | ------------ | -------------------------------------- |
| `eventType` | `string` | Да           | Тип события: `"QuoteRequestCancelled"` |
| `requestId` | `string` | Да           | Идентификатор отменяемого запроса      |
| `timestamp` | `string` | Да           | Время отмены события (ISO 8601)        |
| `reason`    | `string` | Нет          | Причина отмены (если есть)             |

# Топик OsagoQuoteResponse

Событие: QuoteResponseReceived

| Поле                   | Тип      | Обязательное          | Описание                                 |
| ---------------------- | -------- | --------------------- | ---------------------------------------- |
| `eventType`            | `string` | Да                    | Тип события: `"QuoteResponseReceived"`   |
| `requestId`            | `string` | Да                    | Идентификатор исходного запроса          |
| `timestamp`            | `string` | Да                    | Время создания события                   |
| `quotes`               | `array`  | Да                    | Список предложений (может быть пустым)   |
| `quotes.companyId`     | `string` | Да                    | Идентификатор страховой компании         |
| `quotes.companyName`   | `string` | Да                    | Название страховой компании              |
| `quotes.price`         | `number` | Да                    | Стоимость полиса                         |
| `quotes.validUntil`    | `string` | Да                    | Срок действия предложения                |
| `errors`               | `array`  | Нет                   | Ошибки от страховых компаний (если есть) |
| `errors.code`          | `string` | Да                    | Код ошибки                               |
| `errors.message`       | `string` | Да                    | Текст ошибки                             |


# API Core-app

### 1. Создание запроса на предложения

**POST** `/api/v1/osago/quotes`  
Инициирует событие **`QuoteRequestCreated`**

#### Пример запроса

```json
{
  "client": {
    "firstName": "Иван",
    "lastName": "Иванов",
    "birthDate": "1985-06-12",
    "licenseNumber": "1234567890"
  },
  "vehicle": {
    "vin": "1HGCM82633A004352",
    "plateNumber": "А123ВС77",
    "make": "Toyota",
    "model": "Camry",
    "year": 2018
  }
}
```

```json
Response (201 Created)
{
  "requestId": "8fa15c74-88dc-4e4b-b9ce-24f2a879a7b1",
  "status": "PROCESSING"
}
```

### 2. Отмена запроса
**DELETE** `/api/v1/osago/quotes/{requestId}`
Инициирует событие **`QuoteRequestCancelled`**.

```json
{
  "requestId": "8fa15c74-88dc-4e4b-b9ce-24f2a879a7b1",
  "status": "CANCELLED"
}
```

### 3. Получение результатов
**GET** `/api/v1/osago/quotes/{requestId}/results`
Ожидает, что событие **`QuoteResponseReceived`** уже обработано.

```json
{
  "requestId": "8fa15c74-88dc-4e4b-b9ce-24f2a879a7b1",
  "status": "COMPLETED",
  "quotes": [
    {
      "companyId": "alfainsurance",
      "companyName": "АльфаСтрахование",
      "price": 5800.00,
      "validUntil": "2025-05-05T23:59:59Z"
    }
  ],
  "errors": [
    {
      "companyId": "ingosstrah",
      "code": "NO_DATA",
      "message": "Недостаточно данных для расчета"
    }
  ]
}
```

Возможные значения status:
Статус	Описание
PROCESSING	Предложения ещё формируются
COMPLETED	Все предложения собраны и доступны
CANCELLED	Запрос был отменён
FAILED	Произошла внутренняя ошибка при обработке запроса
